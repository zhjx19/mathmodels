# ETS Model Fitting

ETS Model Fitting

## Usage

``` r
ts_ets(x, model = "ZZZ", ...)
```

## Arguments

- x:

  A complete `ts_df` with no missing values.

- model:

  ETS model string passed to
  [`forecast::ets()`](https://pkg.robjhyndman.com/forecast/reference/ets.html).

- ...:

  Additional arguments passed to
  [`forecast::ets()`](https://pkg.robjhyndman.com/forecast/reference/ets.html).

## Value

A list containing tidy model summaries, the raw model, and input.
